# Platform shell

The shell frames every page with its navigation, its account controls and the login dialog. Each
preview holds one state fixed, so dismissing a dialog or a menu leaves it as it was.

Expanded headers show the Agora wordmark, and the compact rail shows its icon. On mobile, the
wordmark and the menu control keep their place between the closed header and the open menu.

Dialog titles and fields share a leading edge. UIKit owns the header controls, the fullscreen menu,
the compact navigation and the action spacing. Service errors sit just above the submit button, which
spans the form on mobile and keeps its natural width on desktop.

Validation previews use the same API schemas as the controllers. Invalid credentials read apart from
a service outage, and a successful login redirects.
